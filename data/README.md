# Data

Every number in the blog post and both figures comes from these files. The spectrum numbers were computed
from the downloaded rollout traces of the training jobs (per-scan `SCAN_OCC` metrics) plus a deterministic
engine replay for the no-memory bound; the second-task numbers were fetched from the job metrics. Runs are
identified by their training-job IDs so each row is traceable to its source job (the complete run history
is [`../REGISTRY.md`](../REGISTRY.md)).

## `raw_occ_traces.csv`  *(the raw data — 54,420 rows, one per episode × scan)*
The unaggregated traces behind the central figure: the occ-IoU of **every scan of every episode of all
four conditions**. [`../code/make_figure.py`](../code/make_figure.py) recomputes the figure and
`occ_by_scan_bin.csv` from this file alone.

| column | meaning |
|---|---|
| `condition` | `no_mem` (scripted memoryless agent), `icl`, or `notepad` |
| `run` | `scripted` for no_mem; otherwise the training-job ID (`g7dncu2c` for ICL; `s8e07n53`/`yp8deoer`/`kym4znjc`/`wqjyy66p` for notepad) |
| `epoch` | `0` (untrained) or `4` (trained) for model conditions; blank for no_mem |
| `episode` | rollout index within that run/epoch (0-based) |
| `row_id` | dataset row (band variant + seed index) the episode was played on |
| `scan` | scan number within the episode (1–30; episodes that truncated have fewer rows) |
| `occ` | occupied-spectrum IoU of that scan's report |

Counts: no_mem 24 episodes; ICL 288; notepad 192 per run per epoch (4 runs × ep0/ep4 = 1,536). Truncated
episodes simply stop early — that is the survivorship bias discussed in the write-up, visible directly here.

## `occ_by_scan_bin.csv`  *(the central figure — `assets/occ_by_scan_bin.png`)*
Occupied-IoU pooled by scan-position bin (scans 1–5, 6–10, …, 26–30) for the four conditions. Generated by
`code/make_figure.py` from `raw_occ_traces.csv` — regenerate it yourself rather than trusting it.

| column | meaning |
|---|---|
| `scan_bin` | scan-position window within the 30-scan episode (`1–5`, `6–10`, …, `26–30`) |
| `no_mem` | occ-IoU of the scripted perfect memoryless agent (upper bound for any memoryless policy) |
| `icl` | occ-IoU of the untrained base model with full history in the prompt, no notepad (job `g7dncu2c`, ep0) |
| `notepad_untrained_ep0` | occ-IoU of the untrained base *with* the notepad tools (4 runs at ep0, pooled) |
| `notepad_trained_ep4` | occ-IoU after RL (4 runs at ep4, pooled): `s8e07n53`/`yp8deoer`/`kym4znjc`/`wqjyy66p` |
| `notepad_trained_run_min` / `_run_max` | min / max of the 4 per-run means in that bin (the whisker) |
| `n_trained_scans` | number of trained-condition scan observations pooled in that bin (falls late = survivorship) |
| `*_ci95_lo` / `*_ci95_hi` | episode-bootstrap 95% CI of each condition's bin mean (2000 resamples of whole episodes, fixed seed — scans within an episode are correlated, so episodes are the resampling unit) |

Notes: `no-mem` is a deterministic engine replay on the same 24 bands, not a model. The notepad bars pool
4 replicate GRPO runs (identical config, different seed); at ep4 completion across the four is
100/97/60/90%, so late bins carry a disclosed survivorship bias (`n_trained_scans` drops from 3840 to 3171).
The bootstrap CI treats the pooled episodes as exchangeable; the run-to-run spread is what the min–max
whisker shows.

## `dbx_second_task.csv`
The `database_exploration` (second task) results — the flat null, the pre-seed learnability diagnostic, and
the sufficiency check (`assets/dbx_second_task.png`).

| column | meaning |
|---|---|
| `run` | training-job ID: baseline nulls (`w7guqqae`/`xvmz0mxv`/`qmi03m6j`/`xmen1ghu`), pre-seed diagnostic (`v7uu671a`), or the local sufficiency smoke |
| `condition` | `empty_notepad (baseline null)` or `oracle_facts_preseeded` |
| `model` | `qwen3-1.7b` or `gpt-oss-120b` |
| `epoch` | training epoch (blank for the one-off sufficiency runs) |
| `acc` | answer accuracy |
| `one_shot` | informed-one-shot rate (correct + ≤1 query at position ≥2, with evidence) |
| `mean_eff` | mean graded efficiency |
| `note` | context |

### Reference values used in the figures (from the writeup, not tabulated per-epoch)
- Spectrum: no-memory upper bound occ ≈ 0.26; late-half (scans 16–30) occ — ICL 0.297, notepad-untrained
  ~0.454, notepad-trained 0.607; scan-1 occ flat trained vs untrained (0.216 → 0.217).
- dbx: null band max-ever acc 0.039; pre-seeded 1.7B acc 0.057 at ep0; gpt-oss-120b sufficiency 0.93 and
  0.67 on the same pre-seeded notepad (a **two-row spot check** — 14/15 and 10/15 questions — through the
  identical evaluator path; a sanity check, not a benchmark).
